# @deepseek-ai/dsh-client-ui-meeting-room

[English](README.md) | 中文

## 概述

此插件将项目工作与会议关联到主会话。项目进度仍在侧边栏工作台中查看。会话页头更多菜单可准备会议请求，或打开该会话发起的真实会议，不再提供独立会议侧边栏入口。参与角色意见与带版本的主助手结论分别展示。

<a id="use-this-package"></a>
## 使用本包

从主会话页头更多菜单选择让主助手安排会议，在该会话准备未发送请求，并保留已有草稿。本会话会议记录打开已保存的讨论、角色会话链接、结论版本和后续行动。记录结论不会确认项目需求。

项目工作台展示保存的员工、团队、最新计划版本、来源背景、真实检查点、交接和验收报告。编辑计划、按保存计划执行、提出调整及放行后续跑，均在关联的主会话准备草稿。无法确定主会话的旧计划提供明确的接续草稿入口，要求助手保留内容、保存关联本会话的新版本并重新确认。

任务执行链接使用已记录的直接父子身份打开现有子智能体会话。根会话既有子智能体目录还会显示同一检查点来源的项目任务页脚。产出数量与验收分别表达，此页脚不创建或完成 Team 服务任务。

| 控制 | 效果 |
|---|---|
| 确认此版本 | 确认精确的最新计划版本。 |
| 确认验收并放行 | 重新核对文件并放行通过检查的人工节点。 |
| 继续下游任务 | 在原主会话准备携带精确检查点的续跑草稿。 |
| 让主助手安排返工 | 在确认次数内准备失败检查点的返工草稿，保留旧报告，任务入口打开最新执行会话。 |
| 刷新进度 | 重新读取项目目录或所选会话的会议。 |

<a id="understand-the-implementation"></a>
## 理解实现

插件挂载 Host projectDashboard Remote，并通过可撤销副作用注册面板、sessionHeader 菜单与既有子智能体页脚。切换会议所属会话会取消前次查询，迟到结果不会写入其他会话。卸载时取消并等待未完成查询。模型工作仅在用户发送准备好的草稿，或主助手调用工具后启动。

SessionMeetings 渲染真实 Host 记录。ProjectPage 与 SessionProjects 共享项目检查点来源。旧原型会议组件不再挂载，也不提供产品数据。

<a id="model-experience"></a>
## 模型体验

### 主会话草稿

#### 模型看到的内容

项目草稿包含 `projectId`、`expectedCheckpoint` 等引用，会议草稿请求使用 `meeting_start` 和 `meeting_record_decision`，仅在发送后进入普通用户输入。读取菜单和报告不产生模型请求。

#### Token 影响

仅发送的草稿内容增加用户输入 token。Host 插件负责工具声明和员工提示词。

#### KV Cache 影响

发送的草稿追加到会话历史，已有草稿按追加方式保留在准备请求之前。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- 进度与会议需要手动刷新，尚无项目事件订阅。
- 会议串行执行独立首轮；自动辩论、需求确认及由结论自动调度任务尚未实现。
- 执行记录中保存直接父子地址后才提供任务链接。未关联的历史会议索引继续保留，不推测发起会话。
- 项目任务摘要复用子智能体页脚，尚未同步到 Team 服务的任务生命周期。
- 主会话调整会准备修订计划，工具执行中的即时纠偏和自动返工尚未完成。
