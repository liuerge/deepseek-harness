# 看板全屏与卡片材质修正

本页记录项目看板的两个后续调整：右上角「全屏查看」把看板放进视口级对话框，以及卡片填充 token 的修正。看板结构与材质基线见 [项目工作台看板改造对照](22-项目工作台看板改造对照.md) 和 [工作台视觉层次调整](23-工作台视觉层次调整.md)。

## 全屏看板

看板标题右侧的「全屏查看」把同一份看板渲染进 `Modal`（`headless`，`aria-label` 为「任务看板」），对话框宽度为 `min(1560px, 100vw - 32px)`、高度为 `100vh - 32px`。

| 项 | 内嵌 | 全屏 |
|---|---|---|
| 列宽 | 五列等分内容宽 | 五列等分对话框宽（1560px 下约 292px） |
| 列高 | 按内容收起，最矮 132px | 撑满对话框高度（最少 56vh） |
| 空列 | 顶部虚线占位「暂无任务」 | 同左 |
| 详情面板 | 看板下方独立面板 | 同左，列区收起到 44vh 给详情让位 |
| 退出 | — | 右上「退出全屏」，或 Esc、点遮罩 |

全屏复用同一个 `renderBoard` 与同一份 `openDetail` 状态：在卡片上点「任务与验收条件」，详情面板出现在列区下方；再次点击收起。内嵌与全屏因此不会出现两份互相独立的选中状态。

全屏不改变数据与操作集：列筛选仍由执行状态决定，卡片按钮与内嵌一致，看板依旧只读（拖放改状态不在范围内）。

## 卡片材质修正

上一轮卡片用 `--dsw-alias-bg-base`，浅色下是 `#ffffff`（比列底 `#f5f5f5` 亮），深色下却是 `#151517`（比列底 `#262628` 暗），观感变成「内嵌卡片」。改为 `--dsw-alias-bg-layer-2` 后两侧方向一致：

| 层 | 浅色 | 深色 |
|---|---|---|
| 对话框 | `#ffffff` | `#2c2c2e` |
| 列底（`bg-skeleton` 叠加） | `#f5f5f5` | `#3a3a3c` |
| 卡片（`bg-layer-2` + `elevation-panel`） | `#ffffff` | `#2c2c2e` |

浅色下卡片与对话框同色，靠列底反差与 0.5px 描边分离；深色下卡片比列底浅一级，与上一轮的方向相反。

## 已知不足

- 全屏仍是覆盖在页面之上的对话框，不是浏览器原生全屏；再按一次 Esc 或点遮罩即退出。
- 预览数据只有成功态，全屏下的受阻、返工、待我处理三列没有真实卡片，只有空列占位。
- 1180px 全屏下列头「查看执行会话」等按钮文字仍会换行。
